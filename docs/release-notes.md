# Project Sasori v0.2.0 — Experimental laboratory

## Device hub update — October 24, 2026

Open the [Device hub](https://jimedusot-beep.github.io/Project-sasori/hub.html) for remembered setups, Elmo sound/volume/touch controls, standard BLE/MiP controls and cancellable saved routines. See the [complete phone directions](device-hub.md).

The [local TV companion](tv-remote.md) adds Roku network control, existing Home Assistant media integrations and learned IR buttons with compatible hardware. TV commands require the companion running on a computer; an ordinary phone cannot emit infrared. Software checks use synthetic radios and upstream APIs. Authentication and physical effects remain unverified on the owner's actual devices.

## Original laboratory release — October 21, 2026

The mobile laboratory now supports bounded BLE inspection, an attributed candidate Elmo profile, packet analysis, persistent local research records, imports/backups, diagnostics, and clearly labeled simulation.

Live authentication and physical voice/motor controls remain unavailable. All Elmo protocol operations beyond metadata inspection and notification subscription require additional evidence and real-device testing. The original V4 source was not recovered.

Validation includes Node transport/protocol/storage/auth tests, lint/format/core type checks, credential-pattern/dependency checks, and desktop Chromium plus iPhone-sized WebKit workflow/accessibility tests. Emulation does not prove Bluefy or real Elmo compatibility.

After successful Pages deployment, the workflow verifies the published HTML, modules, CSS, and icon. See docs/verification.md and the associated Actions run for exact results.

Start on iPhone by opening the published HTTPS site in Bluefy, loading the community-reported profile, and running one authorized inspection. Keep the page foreground. Export backups because records are browser-local and do not sync automatically.
