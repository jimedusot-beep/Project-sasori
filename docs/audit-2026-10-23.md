## Verified boundaries

- Baseline local checks passed 141 Node tests, lint, formatting, typed-core checks and the credential-pattern scan; all nine original desktop tests passed. Root and native dependency audits reported zero known vulnerabilities. These audits describe the pinned dependencies at review time.
- The correction adds full-notebook ASCII/Unicode round trips, exact-capacity IndexedDB and memory restores, native error-category regressions, browser tests for note/autosave overlap, serial note revisions, active deletion, and backup restore. The desktop suite runs the shared web validator against noisy raw and Unicode exports. Final results and CI links are attached to PR #20.
- Runtime inspection found no application characteristic-write, firmware-write, arbitrary executable-import, or runtime network sender in the site/inspection adapters. Unknown imported fields do not create adapters or enable physical actions. Imported and synthetic sessions remain excluded from local physical-evidence counts.
- Metadata backups omit raw packet bytes; desktop raw retention remains explicit. Native export files use protected temporary storage and explicit sharing. Pattern redaction does not establish that arbitrary binary captures contain no secrets.
- Browser tests use synthetic peripherals. Native CI builds and launches the simulator app and waits for its native Bluetooth workspace to render. Neither supplies observations from an actual Elmo or establishes iPhone radio behavior.

## Remaining limitations and follow-up

1. **Real hardware remains unverified.** [M1](https://github.com/jimedusot-beep/Project-sasori/issues/4) still needs five real inspections, sourced services/notification properties, and manual/background stop evidence from the exact Elmo. [M2](https://github.com/jimedusot-beep/Project-sasori/issues/5) still needs documented framing/authentication and independently testable outcomes. No physical-control action is implemented or advertised as verified.
2. **Research remains origin-local.** Browser eviction, clearing data, and separate Bluefy/native/browser origins still require explicit backups. [Private synchronization](https://github.com/jimedusot-beep/Project-sasori/issues/6) is open. Same-tab note saves are serialized; collaborative multi-tab/multi-device conflict resolution is not implemented.
3. **Main was unprotected at review time.** Pages runs tests before deployment, but branch settings do not require pull requests or successful checks before a main-branch update. Repository rules are a separate settings follow-up; this audit does not change them.
4. **Physical iPhone installation needs owner signing/provisioning.** The unsigned simulator build is not an installable signed phone app. Desktop Bluetooth permissions/drivers and physical peripheral compatibility also remain owner-run checks. Live USB/serial/IR/RF adapters are not implemented.

This is a code/reliability audit with synthetic execution and dependency checks. It does not replace firmware analysis or observations on the actual hardware.
