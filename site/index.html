    01 / Label a capture
    
              
    
                
                
                
                
                
                
                
    
                
                
                
                
                
                
                
                
                
    
                  Up to 4,096 bytes or 2,048 positive integer pulse timings. Pulses start with a
                  mark. No code or commands are executed.
                
    
                
              
    
              
    
                Analyze the current form to prepare a capture.
              
    
              
    
                
                
              
    
              
              
    
                Off by default. Raw bytes may contain private information. Metadata-only saves
                cannot reconstruct a capture for later comparison.
              
    
              
            
    
            
    
              
    
                
    02 / Compare two observations
    
                
    
                  Use the same exact model, method, and representation. Select a current analysis or
                  a saved capture with retained values.
                
    
                
    A: no capture selected
    
                
    B: no capture selected
    
                
                
                
    
                  
                  
                
    
                
    
                
    
                  Comparison is by position, without alignment. Repeated or changed values do not
                  prove command meaning, compatibility, or authentication.
                
    
              
    
              
    
                
    03 / Inspect a local sound recording
    
                
    
                  Use the label, exact model, and source above with the Sound method. The first
                  channel is analyzed; the file is never played or uploaded.
                
    
                
                
                
    
                  Mono or stereo · 8–192 kHz · up to 30 seconds and 10 MB. Convert other formats
                  privately before import. Frequencies above half the sample rate are unavailable.
                
    
                
                
    
                  Choose a PCM16 WAV and inspect it locally. Select Sound as the method first.
                
    
                
                
                
    
                  Up to eight 2,048-sample Hann windows, averaged across the recording. A peak alone
                  does not decode an acoustic protocol.
