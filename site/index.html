              What counts toward ten checks?
              
      
                Ten fresh successful sessions with the same model/firmware and observed
                effect/recovery form a report ready for review. Failed, untested or changed-identity
                checks restart the count. Demo/imported trials never count. Owner observations do
                not independently verify hardware or authentication.
              
      
            
      
            
      
              
            
      
            
      
            
      
            
      
              
              
            
      
            
            
      
              
            
      
          
      
          
      
            
      Shared commands, matching adapters
      
            
      
              Standard Bluetooth devices share identity, battery and mild-alert controls where
              exposed. The original WowWee MiP family has a source-cited proprietary version/status
              and timed LED adapter. Shared action names let each supported family use this
              workspace; adding another physical unit does not require reimplementing its family
              protocol. Motion, audio, TV control and firmware commands are not included.
            
      
            
      
              The Elmo remote provides an experimental browser
              known-password handshake, input/volume queries and one greeting request. Native
              inspection remains separate; real-unit testing is pending.
              Elmo source evidence and next steps.

        CAPTURE / DECODE / BUILD SUPPORT
        
              
        Understand the conversation.
        
              
        
                Compare what an app sends with what your toy returns. Keep the evidence, labels, and
                next steps together.
              
        
            
        
            OFFLINE · NO TRANSMISSION
          
        
          
        
            Import normalized TX/RX JSON or CSV. Binary HCI/btsnoop/PCAP extraction is not
            implemented here. Current Sasori sessions provide RX only.
          
        
          
        
            
        
              
        1 / Load a conversation
        
              
              
        
                CSV capture identity (JSON carries its own identity)
                
                
                
                
                
                
              
        
              
              
              
        
                
              
        
              
        
                256 frames · 1,024 bytes per frame · 40 KiB retained raw bytes · 100 markers.
                Imported bytes are analyzed, never replayed to a toy.
              
        
            
        
            
        
              
        2 / Adapter support
        
              
        
                One interface for device-specific evidence, decoders, command definitions, and
                recovery. The Elmo adapter has inspection and historical text analysis; live
                authentication and physical actions remain unavailable.
              
        
              
        
              
              
        
              
        
                Query definitions are offline data. No imported manifest or source claim can enable
                a sender. Physical acceptance target: ten successful fresh connections and actions,
                with rejection, timeout, and recovery tests.

              markers, but cannot reconstruct the bytes. Raw data can contain authentication
              material; review privately.

          01 / Label a capture
          
              
          
                
                
                
                
                
                
                
          
                
                
                
                
                
                
                
                
                
          
                  Up to 4,096 bytes or 2,048 positive integer pulse timings. Pulses start with a
                  mark. No code or commands are executed.
                
          
                
              
          
              
          
                Analyze the current form to prepare a capture.
              
          
              
          
                
                
              
          
              
              
          
                Off by default. Raw bytes may contain private information. Metadata-only saves
                cannot reconstruct a capture for later comparison.
              
          
              
            
          
            
          
              
          
                
          02 / Compare two observations
          
                
          
                  Use the same exact model, method, and representation. Select a current analysis or
                  a saved capture with retained values.
                
          
                
          A: no capture selected
          
                
          B: no capture selected
          
                
                
                
          
                  
                  
                
          
                
          
                
          
                  Comparison is by position, without alignment. Repeated or changed values do not
                  prove command meaning, compatibility, or authentication.
                
          
              
          
              
          
                
          03 / Inspect a local sound recording
          
                
          
                  Use the label, exact model, and source above with the Sound method. The first
                  channel is analyzed; the file is never played or uploaded.
                
          
                
                
                
          
                  Mono or stereo · 8–192 kHz · up to 30 seconds and 10 MB. Convert other formats
                  privately before import. Frequencies above half the sample rate are unavailable.
                
          
                
                
          
                  Choose a PCM16 WAV and inspect it locally. Select Sound as the method first.
                
          
                
                
                
          
                  Up to eight 2,048-sample Hann windows, averaged across the recording. A peak alone
                  does not decode an acoustic protocol.
